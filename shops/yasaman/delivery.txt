روش اجرا
از پوشهٔ اصلی Yasamin که api و shops کنار هم قرار دارند، این دستور را اجرا کنید:
python -m http.server 8765
سپس این نشانی را در مرورگر باز کنید:
http://localhost:8765/shops/yasaman/
می‌توانید Live Server یا npx serve . را هم از ریشهٔ پروژه اجرا کنید.
فایل HTML را با دابل‌کلیک و file:// باز نکنید؛ مرورگر دریافت JSON را مسدود می‌کند.

پاسخ سؤال fetch و 404
fetch برای پاسخ HTTP 404 معمولاً Promise را رد نمی‌کند؛ پاسخ دریافت می‌شود ولی response.ok برابر false است. کد این مقدار را بررسی می‌کند و با throw وارد catch می‌شود. قطع اتصال و JSON نامعتبر هم با catch مدیریت می‌شوند. پیام فارسی نمایش داده می‌شود و خطای مدیریت‌نشدهٔ JavaScript ایجاد نمی‌شود. در تست 404 یا قطع اتصال، مرورگر ممکن است خطای مربوط به درخواست شبکه را در DevTools نشان دهد؛ این با استثنای مدیریت‌نشدهٔ کد تفاوت دارد.

پاسخ سؤال textContent و innerHTML
دادهٔ API باید متن باشد، نه HTML قابل اجرا. textContent اسم و مقدار محصول را به‌صورت متن درج می‌کند تا نشانه‌های HTML احتمالی تفسیر نشوند. خود عناصر با createElement ساخته می‌شوند.

پاسخ سؤال Promise.all
این سؤال از سطح ۲ به بعد لازم است. در سطح ۱ فقط products.json دریافت می‌شود و Promise.all لازم نیست.
