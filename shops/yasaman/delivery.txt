تسک هفتهٔ دوم سوپرمارکت یاسمن — سطح ۱ و ۲

این نسخه بخش‌های سطح ۱ و ۲ را برای نمرهٔ کامل پایهٔ ۱۰۰ تکمیل می‌کند؛ نمرهٔ نهایی را آموزشگاه تعیین می‌کند. سطح‌های ۳ و ۴ و چالش‌های Bonus اضافه نشده‌اند.
کد ساده و بدون کامنت است. JavaScript در app.js قرار دارد و هیچ کتابخانه‌ای استفاده نشده است. داده‌های API با createElement و textContent نمایش داده می‌شوند، نه innerHTML.

روش اجرا
از ریشهٔ پروژه، جایی که پوشه‌های api و shops کنار هم هستند، اجرا کنید:
python -m http.server 8765
سپس باز کنید:
http://localhost:8765/shops/yasaman/
Live Server یا npx serve . نیز باید از ریشهٔ پروژه اجرا شود. HTML را با دابل‌کلیک و file:// باز نکنید.

پاسخ fetch و 404
fetch برای پاسخ HTTP 404 معمولاً Promise را رد نمی‌کند. response.ok برابر false می‌شود؛ readJson آن را بررسی کرده و با throw وارد catch می‌شود. قطع اتصال و JSON نامعتبر هم در catch مدیریت می‌شوند. در صورت شکست هر فایل، هر دو کاروسل پیام خطا می‌گیرند. استثنای مدیریت‌نشدهٔ JavaScript ایجاد نمی‌شود، هرچند DevTools ممکن است شکست درخواست شبکه را نشان دهد.

پاسخ textContent و innerHTML
دادهٔ API متن است و نباید مثل HTML تفسیر شود. با textContent نشانه‌های HTML احتمالی به‌صورت متن نمایش داده می‌شوند و اجرا نمی‌شوند؛ عناصر صفحه با createElement ساخته می‌شوند.

پاسخ Promise.all
سه تابع readJson در آرایهٔ Promise.all بدون انتظار برای پایان درخواست قبلی شروع می‌شوند. ساخت کارت‌ها بعد از آماده شدن هر سه داده انجام می‌شود. درخواست‌های پشت‌سرهم زمان انتظار را جمع می‌کنند؛ در حالت هم‌زمان زمان انتظار بیشتر به کندترین درخواست وابسته است. در Network زمان شروع درخواست‌ها نزدیک هم و نمودار آن‌ها هم‌پوشان است. در تست بدون کش اختلاف شروع سه درخواست کمتر از ۰٫۱ ثانیه بود.

بررسی‌ها
تعداد و نام محصولات، درصد و قیمت تخفیف، قیمت قبلی و disabled بودن دکمه‌ها با فایل‌های اصلی مقایسه شدند.
نمایش در عرض‌های ۳۲۰، ۳۹۰، ۷۰۰، ۷۶۸ و ۱۴۴۰ پیکسل و جهت‌های RTL/LTR بررسی شد.
اسکرول افقی ناخواسته در کل صفحه وجود نداشت. لینک ابتدا و انتها، هم‌ترازی اولین و آخرین کارت و حرکت کیبورد برای هر دو کاروسل بررسی شدند.
پاسخ 404 برای هر یک از سه فایل، قطع اتصال، JSON خراب و بارگذاری کند بررسی شدند.
استثنای مدیریت‌نشدهٔ JavaScript وجود نداشت. نحو JavaScript و اعتبارسنج HTML و CSS بدون خطا گذشتند.
با مقایسهٔ هش‌ها و git diff تأیید شد که داده‌های api تغییر نکرده‌اند.
